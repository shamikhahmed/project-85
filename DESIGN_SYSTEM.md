# Design System — PROJECT 85

## Identity
Apple-inspired calm precision: charcoal surfaces, restrained electric orange (`#FF6A1A`), white primary text, muted secondary. Brand-first hero: **PROJECT** + orange **85**.

## Tokens
See `src/styles/tokens.css` — spacing 4px grid, `--touch: 44px`, safe-area aware `--nav-total-height`.

## Typography
- Display: Syne  
- Body: Manrope  
- Numbers: JetBrains Mono (tabular)

## Themes
Dark default (`data-theme="dark"`). Light supported via Settings.

## Motion
Framer Motion for Nightly Truth sheet only. Forms: no delay animations. `prefers-reduced-motion` respected.

## Components
Panel, metric, badge, btn, progress ring, bottom nav / sidebar, install banner, toast.
